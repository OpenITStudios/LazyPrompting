# Agent Skills and Permissions

Only **foundation routing** exists now. No autonomous browsing skill, runtime agent, or model provider is installed.

- `AGENTS.md` owns global policy and task routing.
- `docs/README.md` routes domain knowledge to one canonical owner.
- Skill modules must be justified by non-overlapping responsibilities and evaluated before creation.
- Permission semantics are deny-by-default; no permission is inferred from skill availability.
- Future browser skills must preserve compliance, authority and proof ceilings.
