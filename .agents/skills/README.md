# LazyPrompting Skill Admission

No executable product skill is installed at this foundation stage. The root policy and governance routing are active source contracts; the permission evaluator is a preflight helper, not a grant of authority.

A proposed skill requires a unique owner, SKILL.md, SPEC.md, SOURCES.md, EVAL.md, explicit permission profile, failure controls, and tested negative cases. Do not import another product's skills wholesale.

Candidate future semantic skill: context-aware continuation planning. It is NOT_INSTALLED until separately justified and accepted.
